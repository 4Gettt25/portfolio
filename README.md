# Felix Günther — Portfolio

Personal portfolio website built with Next.js, showcasing my background in IT infrastructure and business informatics.

**Live:** https://4Gettt25.github.io/portfolio

## Sections

- **About** — bio, personal details, and key facts
- **Resume** — education, experience, and skills
- **Portfolio** — project gallery with detail pages
- **Contact** — contact form backed by Nodemailer

## Tech Stack

- [Next.js](https://nextjs.org/) 12 / React 18
- Bootstrap 5, Boxicons, Remix Icons
- Swiper (project image slider), GLightbox
- Nodemailer (contact form API route)
- GitHub Pages (`gh-pages`) for deployment

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deployment

```bash
npm run deploy
```

Builds the static export and pushes it to the `gh-pages` branch.

## Data

All content (bio, resume entries, portfolio projects, skills) lives in the `Data/` directory and can be edited without touching any component code.
